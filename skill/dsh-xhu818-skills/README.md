# dsh-xhu818-skills

给 **DeepSeek Harness (DSH)** 用的技能包，服务于「西华大学 818 工程流体力学」这门考研专业课。包含两个技能：

| 技能 | 什么时候用 |
|---|---|
| **`xhu818-fluid-tutor`** | **学生自己复习时随手调用**：扔过来一道不会做的题（拍照／扫描 PDF／直接打字）、一个没听懂的知识点、或问「这题重要吗／会不会考／书上有类似例题吗」。用已经整理好的知识库当场讲明白：逐步演算、给教材页码与公式号、点出易错点，并说明该考点在 818 里的重要度（星级＋文件依据）。 |
| **`exam-prep-latex`** | **生产流程**：把扫描教材＋历年真题＋题库做成一套中文考研 LaTeX 讲义（教材精讲／课后习题／历年真题与答案／题库汇编／辅导书题选），并且每一条「重要程度」星级都必须挂在可追溯的文件证据（E1–E6）上，不许主观打分。 |

## 为什么需要它

818 备考有两个具体的痛点，这个技能包就是冲着它们去的：

1. **做题时没人问。** 教材《流体力学与流体机械》（赵琴主编）第 1–8 章的正文改写、**26 道教材编号例题的完整题目与解答**、2014–2022＋2026 回忆版真题与答案、课后习题解答、题库、孔珑辅导书题选，都已经整理成**纯文本 LaTeX 源**——可以直接 grep。绝大多数问题都能先在库里找到现成答案，模型要做的是找到它、验算它、然后用人话讲清楚。
2. **「重点」是主观的。** 五份资料的每一处星级都标注了依据来源，共用一套证据编号：
   - **E1** `8-1考情分析.pptx`（题型分值／各题型考法／出题风格／逐章重要度）
   - **E2** `9-1考点分析.pptx`
   - **E3** `西华大学 818工程流体力学考研分析.docx`
   - **E4** 历年真题 2014–2022 ＋ 2026 回忆版
   - **E5** 题库
   - **E6** 赵琴教材

   判定规则（`star_rubric.md`）：★★★★★ ＝ E4 计算题出现 ≥3 次，或 E1/E2 明写「考试计算题重点」；★★★★ ＝ 出现 2–3 次或「重点掌握」；★★★ ＝ 出现 1 次或「掌握基本概念与公式套用」；★★ ＝ 真题未出现但属考纲核心／题库常客；★ ＝ 边缘或复试内容。

## 安装

把整个包放进 DSH profile 的 `node_modules`，并把包名加进该 profile `package.json` 的 `dsh.profile.bundles`（**不要**写进 `dependencies`，否则 pnpm 会去 registry 找它）：

```powershell
$prof = "C:\Users\<你>\.dsh\profiles\desktop"
Copy-Item -Recurse -Force . "$prof\node_modules\dsh-xhu818-skills"
```

```jsonc
// $prof\package.json
{ "dsh": { "profile": { "bundles": [ /* … */ "dsh-xhu818-skills" ] } } }
```

刷新即生效，不必重启。

## 技能之间的分工

`xhu818-fluid-tutor` 只在**答疑**时读知识库（`latex/*/parts/*.tex`）；`exam-prep-latex` 负责**把知识库编成 PDF**。两者共用同一套证据编号与写作规范（`WRITING-SPEC.md`、`EXAM-SPEC.md`、`star_rubric.md`）。
