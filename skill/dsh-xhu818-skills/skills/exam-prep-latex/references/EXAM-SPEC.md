# 真题册（03-exams）撰稿规范

本文件是 `xhu818\latex\03-exams\` 全部撰稿子代理的**必读规范**。请严格照此写作，
否则编译会失败或风格不统一。

## 1. 任务

把扫描件 OCR 出来的历年试题 / 答案，**人工校对后**转写成排版精良的 LaTeX。
OCR 有错字（例如 `Pbs` 应为 `p_{abs}`、`Ah` 应为 `\Delta h`、`m7/s` 应为 `m^3/s`），
你必须用流体力学常识与上下文**改正**，不能照抄乱码。

**输入**：`xhu818\02-ocr\exams\<年>年试题\merged.txt`（或同目录 `page-000N.txt`）
**输出**：

- 试题 → `xhu818\latex\03-exams\parts\q-<年>.tex`
- 答案 → `xhu818\latex\03-exams\parts\a-<年>.tex`（2026 回忆版是 `q-2026recall.tex`，已写好，不要改）

## 2. 必须使用的样式（`xhu818.sty` 已提供）

| 用法 | 含义 |
|---|---|
| `\chapter{2014 年 818 工程流体力学试题}` | 每一年的试题/答案各占一章 |
| `\section{一、选择题（共 30 分，每小题 3 分）}` | 各大题 |
| `\begin{ti} \item ... \end{ti}` | 题目列表（自动编号） |
| `\begin{xiaowen} \item ... \end{xiaowen}` | 大题内的小问 (1)(2)(3) |
| `\begin{choices} \item 选项1 \item 选项2 \item 选项3 \item 选项4 \end{choices}` | 选择题选项（(A)(B)(C)(D) 自动） |
| `\fourchoices{甲}{乙}{丙}{丁}` | **四个选项都短（≤ 16 字）时**用，排成 2×2 节省篇幅 |
| `\tuyi{...}` | 原卷有图时的**文字图示说明**（见第 4 条） |
| `\begin{jie} ... \end{jie}` | 解答开头（自动加"解："） |
| `\xstarfull{n}` | 重要度 0–5 颗星 |
| `\yiju{...}` | 〔依据：…〕 |
| `\nandu{易/中/难}` | 难度标签 |
| `\begin{yicuo}...\end{yicuo}` | 易错点（红框） |
| `\begin{banfa}...\end{banfa}` | 书上没有的方法/技巧（蓝框） |
| `\begin{tishi}...\end{tishi}` | 一般提示（灰框） |
| `\begin{jielun}...\end{jielun}` | 结论（绿框） |
| `\begin{gongshi}{公式名} 公式 + 含义 + 适用条件 \end{gongshi}` | 公式框 |
| `\begin{zhenti}{出处}{题型}` | 真题出处框 |

**绝对不要写这些字符**：`★`（用 `\xstarfull{}`）、`≠`（用 `$\neq$`）、`§`、`→` 以外的生僻箭头。
`①②③` 可以写。`\Re` 不可用（用 `\Rey`）。

## 3. 每道题必须标重要度（**这是用户的硬要求：不许凭印象**）

**第一遍（你）**：在题干末尾（选项之前）加**考点码占位标记** + 难度：


**不要自己判星**（星由第二遍的统一星表统一裁定，避免不同年份口径不一）。

**第二遍（主代理）**：由全科星表把 `\xstarmark{Kxxx}` 统一替换成 `\xstarfull{n}\yiju{...}`。

## 4. 图怎么办（**关键：不允许凭想象编图**）

原卷许多题配图（U 形水银压差计、管路与测压管、闸门、弯管、孔口/管嘴、虹吸管、
平板射流冲击、文丘里管、势流叠加等）。

要求：

1. **不要用 TikZ 画图**（风险高、易编译失败）。
2. 用 `\tuyi{...}` 写一句**足够解题的准确文字描述**，例如：
   `\tuyi{一容器右侧壁接一根 U 形水银测压计；管中 1、2、3 三点在同一水平面上，1 点在容器内液体中，3 点在水银面上方的水柱中。}`
3. 同时在题末写 `\yiju{}` 后附一句 `原卷影印见本册附录`（用 `\tishi{}` 或直接括注）。
4. 描述必须**只依据 OCR 文字与上下文的物理合理性**，不确定的地方写"原卷图略，请对照原卷"，
   **不要编造尺寸或位置关系**。

## 5. 答案章（`a-<年>.tex`）的写法

答案卷是**手机拍照**，OCR 质量比试题差，公式常常缺漏。要求：

- 开头 `\chapter{2014 年 818 工程流体力学试题参考答案}`，然后 `\begin{tishi}` 说明
  "本答案由原卷拍照件整理，个别步骤与符号已按流体力学标准写法规范化"。
- 用 `\answ{一、选择题}` 分大题，然后按题号给出答案。
- 选择题/填空题给**简洁答案**，可以几题一行：`1. A\quad 2. C\quad 3. B ...`
- 计算题给**完整解题步骤**：已知 → 求解目标 → 公式 → 代入 → 结果（带单位）。
  你必须**自己把物理算通**（OCR 缺失的数字要依据题设重算，并保证量纲与数量级合理）。
- 对 OCR 模糊、无法确定的步骤，写 `\begin{tishi}原卷此处字迹不清，按标准解法补全。\end{tishi}`，
  **不要装作原文如此**。

## 6. 排版约定

- 数字与单位之间用 `\,`（如 `30\,\mathrm{kN/m^2}`）或直接写（如 `5 m`），全篇统一。
- 变量斜体、单位正体：用 `$Q$`、`$\mathrm{m^3/s}$`。
- 公式用 `\[ ... \]` 独立行，或 `$...$` 行内。
- 每章末尾不要加小结（真题册不需要）。
- 文件末尾不要写 `\endinput`，也不要写 `\chapter` 之外的文档类命令。

## 8. 实测踩坑与已达成的口径（2015/2016/2018 代理实测，后续撰稿人必读）

### 8.1 tcolorbox 绝对不能放进 `\item` 内部（**最高优先级**）

`tishi` / `yicuo` / `jielun` / `gongshi` / `banfa` / `kaodian` / `zhenti` 全是 tcolorbox 环境。
把它们写在 `\begin{ti}...\end{ti}`（即 `enumerate`）的某个 `\item` 里面，编译必报：

```
! LaTeX Error: \begin{tcb@savebox} on input line NN ended by \end{enumerate}.
```

整册 PDF 全废。**正确写法**：题干与选项只写在一行 `\item` 里，
所有说明框提到 `\end{ti}` 之后，按"第 N 题：……"分条列出。
`\tuyi{...}`、`\fourchoices{...}`、`\begin{choices}` 不是 tcolorbox，放在 `\item` 里没问题。

### 8.2 科目代码逐年变动（**不是笔误，不要统一改成 818**）

原卷 OCR 逐字读出的科目代码：

| 年份 | 原卷科目代码 |
|---|---|
| 2014 | 818 |
| 2015 | 819 |
| 2016 | 817 |
| 2017 | 819 |
| 2018 | 819 |
| 2019 | 821 |
| 2020 | 818 |
| 2021 | 818 |
| 2022 | 818 |

2018 年已用 pdftoppm 渲染原卷第 1 页目视复核，确为「819 工程流体力学」，OCR 无误。
**写法**：章标题写「20XX 年工程流体力学试题（当年科目代码 8XX）」，括号里**如实写当年代码**，
并在章首 `tishi` 里说明"当年科目代码与现行的 818 不同，但考查内容体系一致"。
不要一律写成 818。

### 8.3 选项一律用 `choices` 环境，不要用 `\fourchoices`

`\fourchoices{甲}{乙}{丙}{丁}` 是两列排版，早期版本在 `\item` 内部曾把 enumerate 打断。
最小测试（`xhu818\latex\_smoke\t4c.tex`）现在能编过，但为了**保持一致、不再踩坑**，
全项目统一规定：**四个选项一律写成**

```latex
\begin{choices}
  \item 选项甲
  \item 选项乙
  \item 选项丙
  \item 选项丁
\end{choices}
```

`choices` 本身就是一个 `enumerate`，嵌在 `\item` 里也合法。
