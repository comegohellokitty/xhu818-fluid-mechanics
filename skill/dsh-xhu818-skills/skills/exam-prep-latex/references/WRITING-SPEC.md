# 写作规范（01-textbook 教材精讲）— 所有撰稿子代理必须严格遵守

## 0. 目标

产出西华大学 818 工程流体力学「教材精讲」的一章内容，服务对象是**应试考生**。
参考教材：赵琴主编《流体力学与流体机械》（中国水利水电出版社，2016，ISBN 978-7-5170-4239-6）**第 1–8 章**。

**用途决定写法**：考生打开这一章，要能立刻看到每个考点的
① 它是什么 → ② 核心公式的**含义**与**适用条件**（**公式一律不证**）→
③ 常考什么、考什么题型 → ④ 多重要（星级）→ ⑤ 难度 → ⑥ **书上没有的方法/应试技巧**。

## 1. 输出形式

* 只输出**一个** `.tex` 片段文件（不含导言区、不含 `\documentclass`、不含 `\begin{document}`）。
* 文件以 `\chapter{章名}` 开头，以本章小结表结尾。
* 章名用赵琴书的原名（如 `\chapter{流体静力学}`）。

## 3. 星级的写法（**硬性要求**）

* **绝对不要写 `★` 字符**（字体缺字）。一律用 `\xstarfull{n}`，如 `\xstarfull{4}` 渲染成 ★★★★☆。
* 星级只能来自**给定的证据清单**，不得凭印象。写法：

```latex
\textbf{重要度 \xstarfull{4}}\quad\yiju{E4 2022 年 818 单选第 3 题；E1 slide33「第二章＝计算题基础入门、重点掌握方法」}\quad\nandu{中}
```

* `\yiju{...}` → 〔依据：…〕；`\nandu{易|中|难}` → [易]。
* **严禁编造年份或题号**。只能引用证据清单里明确列出的真题/题库条目。
  若某考点没有直接题号证据，依据就只写章节级的 E1/E2 原文（如 `\yiju{E2「第四章是主要考点，需掌握计算套路」}`），
  再把星级压在 ★★★ 及以下（除非 E1/E2 明确说该章是重点）。

## 4. 行文要求

1. **公式不证**，但必须紧跟「含义：…」「适用条件：…」两行（放在 `gongshi` 盒内）。
2. 概念定义**用教材口径**（若能读到赵琴 OCR 原文，优先用书的原话）。
3. 每个考点末尾给出：常考题型 + 星级 + 依据 + 难度。
4. 计算类考点必须给出「**解题步骤套路**」（放 `banfa` 盒），写成 ①②③ 步骤。
   注意：`① ② ③` 可以直接写在正文里（字体已处理）。
5. 语言：简体中文，简洁，多用短句与表格；不要客套话，不要「综上所述」式废话。
6. 数学：行内 `$...$`，行间 `\[ ... \]`。符号：用 `\rho \mu \nu \tau \gamma`、`\dd` 表示直立体 d、
   `\Rey` 表示雷诺数（**不要用 `\Re`**）、`\bq \bv \bn \bF \bu \bomega` 表示矢量、`\grad` 表示 ∇。
7. 表格用 `booktabs` 的 `\toprule \midrule \bottomrule`，宽度用 `tabularx` 的 `X` 列：
   `\begin{tabularx}{\textwidth}{@{}lXX@{}}`。
8. 不要插图、不要 `\includegraphics`、不要引用外部文件。
9. 每章末尾给一个「本章小结」表：三列 `考点 | 重要度 | 一句话抓住`（可再加难度列）。
