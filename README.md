### 命题风格

1. 重视基础，新题型很少；
2. **真题重复率很高**——同一考点会换数字反复考；
3. 题量适中，计算量适中；
4. 围绕参考书复习即可；
5. 总体难度中等；
6. **每年的真题大部分都源于课后习题的改编，课后习题必须逐题过关**。

## 三、星级评审依据（本套资料最重要的设计）

用户/编者对"重要程度"的要求是：**必须有文件依据，不能凭主观臆断**。因此本套资料建立了一套
**证据制**打星规则，每一颗星都能回溯到具体的文件与原句。

### 证据清单

| 代号 | 文件 | 用途 |
| --- | --- | --- |
| E1 | `8-1考情分析.pptx` | 题型分值、出题风格、逐章复习规划 |
| E2 | `9-1考点分析.pptx` | 分值与考点分布，指出计算题占 50% |
| E3 | `西华大学 818工程流体力学考研分析.docx` | 官方参考书与考试范围、资料清单 |
| E4 | 历年真题 2014–2022 + 2026 回忆版 | 考点在真题中的**实际出现次数与题型** |
| E5 | 题库类资料（试题库、选择题库） | 考点的练习密度 |
| E6 | 赵琴教材正文 | 该内容是否属于考纲核心 |

### 判定规则

| 星级 | 含义 | 判定条件（满足其一） |
| --- | --- | --- |
| ★★★★★ | 必做 | 对应考点在历年真题中作为计算题出现 ≥3 次，或考情分析明列为"考试计算题重点" |
| ★★★★ | 高频 | 真题中出现 2–3 次，或考情分析写"重点掌握" |
| ★★★ | 常考 | 真题中出现 1 次，或考点分析写"掌握基本概念与公式套用" |
| ★★ | 了解 | 真题未出现，但属考纲核心内容 |
| ★ | 边缘 | 仅作扩展 |

难度记号 `[易] / [中] / [难]` 按解题步骤数判定：一步套公式 = 易；选断面 + 列方程 + 联立 = 中；需积分/极值/耦联 = 难。

## 五、自行编译

要求：TeX Live 2023+（需 `xelatex` + `latexmk`）、Windows 字体集。

```powershell
# 1. 把 TeX Live 加进 PATH（按自己的安装路径改）
$env:PATH = "D:\latex\texlive\2024\bin\windows;" + $env:PATH

# 2. 一键编译五份文档（会把 common/xhu818.sty 复制进各子目录）
cd xhu818\latex
.\build-all.ps1
```

或单独编译某一份：

```powershell
cd xhu818\latex\01-textbook
Copy-Item ..\common\xhu818.sty .\xhu818.sty -Force
latexmk -xelatex -interaction=nonstopmode -file-line-error -halt-on-error main.tex
```

> 注意：`-output-directory` 必须用双引号包住绝对路径，否则 Windows 会把它展开成 8.3 短名并报
> `I can't write on file 'main.log'`。

## 六、配套技能：`exam-prep-latex`

本项目的整套流程已抽成一个可复用的技能包，位于 `skill/`——目录本身就是可安装的 DSH 插件包：

```
skill/
├── INSTALL.md                     安装说明（拷进 profile + 加进 bundles）
└── dsh-xhu818-skills/             DeepSeek Harness 插件包（skill-only bundle）
    ├── package.json               name=dsh-xhu818-skills、main → lib/index.mjs
    ├── cordis.patch.yml           一条 insert 条目 → 加载本包
    ├── lib/index.mjs              注册逻辑（读 SKILL.md → ctx.get("skills").register）
    └── skills/exam-prep-latex/
        ├── SKILL.md               技能正文（五份文档的产出流程、星级铁律、各阶段踩坑）
        ├── assets/xhu818.sty      样式表（可直接复制到新项目）
        ├── references/            WRITING-SPEC.md / EXAM-SPEC.md / star_rubric.md
        └── scripts/               ocr_pdf.py、ocr_batch.py、make_manifest.py、star_table.py、build-all.ps1
```

技能要点：

- **星级必须有文件依据**：先建立证据清单 E1…En（考情分析、考点分析、真题、题库、教材），
  每题末尾强制打印〔依据〕，禁止编造年份题号；跨文档一致性用"考点码表 + 映射脚本"保证，
  而不是靠人肉记忆（见 `scripts/star_table.py`，第一遍下游只写 `\xstarmark{Kxxx}`，第二遍统一替换）。
- **扫描件 OCR**：`scripts/ocr_batch.py` 支持"一页失败不中断整册"；`scripts/ocr_pdf.py` 内置
  `install_safe_cv2_resize()` 修复 RapidOCR 在高负载下 `cv2.resize` 抛
  `Unknown C++ exception from OpenCV code` 的间歇性故障。
- **中文 LaTeX 三个高频坑**：`\text{}` 里不能出现中文标点；`★ ≠ ≤ ≥ √ §` 等必须走宏或数学模式；
  tcolorbox 环境绝不能放进 `\item`。
- **验收不能只看 `^!`**：`-file-line-error` 会把行首 `!` 替换成 `./file.tex:N:`，
  只统计 `^!` 会漏报全部真实错误——必须同时统计 `Undefined control sequence`。

安装为 harness 技能（本机做法，见 `skill/INSTALL.md`）：把整个包放进
`<profile>/node_modules/dsh-xhu818-skills/`，在 profile 的 `package.json` 的
`dsh.profile.bundles` 里加上 `"dsh-xhu818-skills"`，插件通过 `ctx.get("skills").register(...)`
把技能注册进 agent 作用域。

## 七、排版约定（编者备忘）

- 中文必须用 **XeLaTeX**；`ctexbook` + `fontset=windows`。
- **正文行文里不要写 `★`**——一律用 `\xstarfull{n}`。（星级对照表里可以直接写，样式表已把
  U+25A0–U+26FF 交给中文字体；但早期没做这个声明时 lmroman 缺字形，会报 `Missing character`。）
- `≠ ≤ ≥ √` 等数学符号优先写成 `$\neq$`、`$\le$`、`$\surd$`；`§` 与希腊字母一律进数学模式。
- 用 `\Rey` 而不是 `\Re`（`\Re` 是 LaTeX 内建的实部符号，重定义会报错）。
- **tcolorbox 环境（`tishi` / `yicuo` / `jielun` / `gongshi` / `banfa` / `kaodian` / `zhenti`）
  绝对不能放进 `\item` 内部**，也不能跨 `\end{enumerate}`，否则报
  `! LaTeX Error: \begin{tcb@savebox} on input line N ended by \end{enumerate}.`
  正确做法是把说明框提到 `\end{ti}` 之后。
- 选项一律用 `choices` 环境。
